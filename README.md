# Keypad Lock

Sistema de teclados/candados para cofres y puertas de hierro del pack Hard
Death: contraseñas, propiedad y reforzamiento controlados por el servidor,
para Minecraft 26.2 (Fabric).

- **Minecraft**: 26.2 · **Loader**: Fabric · **Lenguaje**: Kotlin (fabric-language-kotlin)
- **Lado**: cliente + servidor (`splitEnvironmentSourceSets`)

## Compilar

```bash
./gradlew build
```

El jar queda en `build/libs/`.

## Distribución y actualizaciones

Este mod se distribuye vía [hd-updater](https://github.com/NicolasBeatum/hd-updater),
que compara la versión instalada contra la última release y ofrece actualizar
automáticamente al abrir Minecraft.
